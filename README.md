# 🎵 Spotify Clone (HTML + CSS)

This is a simple "Spotify Clone" built using only "HTML and CSS". The goal of this project was to replicate the basic layout and design of the Spotify web interface as closely as possible using pure frontend technologies.

🚀 Features

- Responsive layout
- Navigation sidebar
- Header with controls
- Playlist section
- Footer player bar (static)
- Clean and organized code

⚠️ This clone is for **educational purposes only** and does not contain any real music functionality or Spotify backend.

🛠️ Tech Stack

- HTML5
- CSS3
- Font Awesome (for icons, if used)
- Google Fonts (optional)
